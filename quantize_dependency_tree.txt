调用流程图 (Call Flow Diagram)
====================================

量化主流程:
├─ quantize() ◄───────── 主入口
│   ├─ _get_input_feat() ── 获取所有层的输入特征
│   │   └─ 使用前向钩子捕获输入数据
│   ├─ _search_best_scale() ── 计算最佳缩放因子
│   │   ├─ _compute_best_scale() ── 网格搜索最优比例
│   │   │   └─ _compute_loss() ── 计算量化误差
│   │   └─ apply_scale() ── 应用缩放到层权重
│   ├─ _search_best_clip() ── 计算最佳裁剪阈值
│   │   ├─ _compute_best_clip() ── 网格搜索裁剪值
│   │   └─ apply_clip() ── 应用裁剪到权重
│   └─ _apply_quant() ── 执行实际权重量化

内存管理流程:
├─ clear_memory() ── 在关键步骤释放GPU内存
├─ get_best_device() ── 智能选择CPU/GPU设备
└─ 设备移动策略 ── 按需在CPU/GPU间移动张量

数据流:
├─ init_quant() ◄───────── 准备校准数据
│   ├─ get_calib_dataset() ── 获取量化校准样本
│   ├─ Catcher类 ── 捕获第一层输入/参数
│   └─ 返回: modules, kwargs, inputs
│
├─ _get_input_feat() ◄──── 输入特征提取
│   ├─ cache_input_hook ── 注册前向钩子
│   ├─ _module_forward() ── 执行前向传播触发钩子
│   └─ cat_and_assert ── 处理并验证特征数据
│
└─ quantize()处理各层后:
    └─ _apply_quant() ── 应用量化替换线性层
        └─ WQLinear_* 系列 ── 各后端量化实现
